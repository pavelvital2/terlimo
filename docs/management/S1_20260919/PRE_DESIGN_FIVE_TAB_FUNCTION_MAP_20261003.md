## Утверждённая владельцем навигация03.10

Пять основных вкладок: **Главная → Подписка → Пригласить друга → Настройки → Помощь**. «Пригласить друга» — отдельная реферальная вкладка с иконкой подарка. Маршрутизация переносится внутрь «Настроек» со всеми существующими функциями. «Помощь» остаётся самостоятельной вкладкой. Предложение root перенести помощь в настройки отклонено владельцем.

Уточнение владельца: в «Настройках» размещается кнопка «Маршрутизация». Нажатие открывает отдельный вложенный экран со всеми настройками маршрутизации; действие «Назад» возвращает в «Настройки». Это вложенный экран, число основных вкладок остаётся пять. Существующая логика и настройки маршрутизации сохраняются.

Уведомления — согласовано владельцем: во вкладке «Помощь» отдельный раздел «Новости и уведомления» с полным списком новостей сервиса, новых серверов, технических работ и сообщений с разрешёнными действиями. Сохраняются отметки прочитанного и счётчик непрочитанных на значке «Помощь». Сообщения, требующие действия для подключения, дополнительно показываются на «Главной» короткой карточкой с нужной кнопкой (например, «Список серверов изменился» → «Обновить»). Это одно сообщение с общим состоянием прочтения, не две независимые рассылки. Действие использует штатное обновление каталога, не создаёт отдельный механизм refresh. Внешний вид и компоновку карточек/списка уточнить при дизайне; сейчас согласовано функциональное размещение.

Это принятое расположение основных разделов; таблица ниже сохраняет source-инвентаризацию предыдущего состояния, а прежние строки отдельной «Маршрутизации» и приглашений в «Подписке» не являются актуальным требованием размещения. ## Общие окна — без шестой вкладки

- CAPTCHA: существующее окно текущего challenge, кнопка открытия на Главной только при pending, возврат и штатная отмена. Отдельного пользовательского переключателя «Режим CAPTCHA» в проверенном MainActivity нет; убрать утверждение «существующая настройка» из карты. Новую настройку этим предложением не вводим.
- Оплата: СБП подписан «QR-код», но wire не содержит QR-данных. QR/выбор банков — во внешнем provider checkout. Не рисовать внутренний QR-экран или сканер. Возврат из браузера не равен оплате: статус и свежие права обязательны.
- Обновление: предложение может появиться поверх текущей вкладки; центр управления — Настройки. Отдельное подтверждение «Установить сейчас/Позже», затем системный Android installer. Возврат из installer сам по себе не успех.
- Ошибка на Главной ведёт в один recovery editor или поддержку; срок доступа — в Подписку. Уведомление VPN и системные согласия остаются общими окнами.
