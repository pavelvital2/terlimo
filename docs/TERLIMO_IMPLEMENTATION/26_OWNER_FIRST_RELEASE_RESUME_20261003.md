# Возобновление первого релиза — решения владельца 03.10.2026

Павел возобновил исполнение после обсуждения. Используются существующие исполнители Laptop/TERLIMO и Codex; неизменные модели/сессии, root — единственный publisher. Паузы, записанные в исторических обсуждениях, сняты этим указанием. Production writes требуют отдельной согласованной области; текущий этап SOURCE и затем TEST.

- Первый релиз без Always-on; исходный код сохранён для последующего обновления, AT22 отложен. Обычные подключение/удержание/автоподключение при открытии сохраняются.
- Пять вкладок: Главная, Подписка, Пригласить друга, Настройки, Помощь. Маршрутизация — вложенный экран Настроек. Аккаунт/регистрация/trial/оплата/устройства — Подписка; Главная даёт текущее контекстное действие, час/trial только по явному нажатию.
- Новости/уведомления — Помощь, read/unread и badge; требующие действия для подключения также на Главной, одно состояние.
- Recovery: оба канала выдачи (бот и сайт) обязательны в первом релизе, без покупки/повторной регистрации; Settings editor + две кнопки получения. Ручной transport/persistence recovery уже принят, его не повторять ради выдачи.
- Рефералы: постоянный уникальный код аккаунта после Telegram регистрации; входной чужой код до неё. Час не даёт referral бонуса. Подходящий trial приглашённого10дней (7+3); бессрочные100₽ скидки на первую успешную основную подписку1/3/6месяцев. Отменённая/неуспешная оплата скидку не тратит, trial не обязателен. Пригласившему прежние +7заtrial и отдельно +7/+14/+30за первую оплату. Без активного доступа заработанное ждёт, новый доступ бонусом не создаётся. Свой код можно делиться без активного доступа; приглашённый получает свой код. Все условия одинаково понятны в приложении/боте/на сайте. Прежние50% и срок10дней для скидки отменены.

Порядок: параллельно client navigation/release exclusion, server recovery issuance, readonly referral wire/transaction contract. Затем согласовать клиент/сервер, реализовать referral, принять source, одна совместимая сборка/адресные TEST сценарии. Дизайн — после функционального распределения, административная панель — по прежней очередности после дизайна до внешнего выпуска. Recovery и actual updater15→16 приняты и не повторяются без затронутой регрессии.
